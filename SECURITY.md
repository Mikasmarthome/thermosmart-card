# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues.

Instead, use [GitHub Security Advisories](https://github.com/Mikasmarthome/thermosmart-card/security/advisories/new) to report a vulnerability privately.

Include as much detail as possible:
- Description of the issue
- Steps to reproduce
- Potential impact

## Scope

This policy applies to the ThermoSmart Card Lovelace custom component.

## Non-Security Bugs

For general bugs and feature requests, please open a [GitHub Issue](https://github.com/Mikasmarthome/thermosmart-card/issues).
